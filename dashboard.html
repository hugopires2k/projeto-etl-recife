⚙️ ARQUITETURA DO PIPELINE ETL

1
Extração · Consulta às APIs CKAN do portal dados.recife.pe.gov.br, API SINESP, Fogo Cruzado e portais das Secretarias
2
Transformação · Limpeza, normalização, cálculo de KPIs, agregações por bairro/tipo/período com pandas
3
Validação · Verificação de tipos, tratamento de nulos, fallback para dados simulados quando API indisponível
4
Carga · Exportação em CSV por tema + KPIs consolidados em JSON para consumo do dashboard
5
Visualização · Dashboard interativo HTML/CSS/JS com Chart.js, navegação por abas, gráficos e tabelas
